💰 Расход ИИ
Каждое обращение к модели из сервиса — строка журнала: гейт, заключения, пересказ, разбор аварии, очистка языка, площадка. Токены — как их отдал провайдер: «вход» — без кэша, «кэш» — прочитано из кэша; чего провайдер не сообщил — прочерк, а не ноль. Стоимость считается по ценам записи реестра на момент вызова; у вызовов без цен её нет — рядом показано, сколько вызовов оценено. Журнал хранится построчно 90 суток, старше — суточными итогами.
